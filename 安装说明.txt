Agent 轨迹可视化 v2.1 — 安装说明（发同事测试版）
====================================================

这是什么
--------
把 pi（终端 agent）的会话日志解析成可视化轨迹回放页：
四区结构（Agent层 / 资料架 / 上下文 / 大模型），滚轮逐步回放，
能看清一个对话里 agent 动了哪些资料、跑了什么命令、上下文怎么被装满/压缩。

前提
----
1. 电脑上有 pi，且至少跑过几个对话（会话日志在 ~/.pi/agent/sessions/）
2. python 3.8+（只用标准库，无需 pip 装任何东西）

安装（30 秒）
--------
把 agent-trajectory 文件夹整个解压到：
  Windows:  C:\Users\<你的用户名>\.agents\skills\agent-trajectory\
  macOS:    ~/.agents/skills/agent-trajectory/

用法 A：手动跑（不依赖 pi，最简单）
--------
1. 在该文件夹打开终端，运行：
     python -X utf8 build_library.py
   （自动扫你机器上的全部会话，生成 lib/，并打印逐对话统计表）
2. 双击 agent-trajectory-replay.html 即可回放（零依赖，无需服务器）
3. 之后有新对话，重跑第 1 步刷新即可

实时跟踪（看某个对话的最新动态）
--------
1. 在该文件夹运行：python -X utf8 live_server.py
2. 浏览器打开 http://localhost:8765
3. 正常「📂 载入对话」选任意话题 → 点右上「🔴 跟踪」
4. 页面跳到该对话最近一轮；之后新对话内容写入自动续跟；
   滚轮回看历史会暂停跟随，点「▶跳到最新并恢复跟随」回来
   （跟踪=载入后的动作，file:// 双击方式不支持跟踪）

用法 B：对 pi 说
--------
新开 pi 对话，说「轨迹回放」或「看看我的对话运行情况」，
pi 会自动调用本技能（建库+开页+解读统计）。

页面操作
--------
左侧选对话 → 滚轮/方向键逐步回放，一下一根线
- 上下文条目：悬停看详情，点击画蓝线→资料架原件位置
- 资料架条目：点 ↗ 打开原文件
- 图标：📄读 ✏️写 ⌨️终端 🧷平台注入 📖技能 🌐网页 🔐人工闸门 📁文件夹

已知边界（测试时请留意）
--------
- tokens 有两类口径：统计条「真耗」=usage 真值（含缓存重发）；
  条目上的「装包」为字符估算，报告里会说清
- 子 agent 只显发起/回包，内部轨迹不下钻（v2 规划）
- pi 版本差异可能使部分工具落到「⌨️执行」兜底类——遇到请截图反馈
- 解析器只绑 pi 日志格式，Claude Code / Codex 格式未接入

反馈渠道：发现漏事件/分类错/页面报错，把会话文件名+截图发给发布人。
